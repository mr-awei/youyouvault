01

它解决的是这些很具体的小事

不讲"赋能""生态"，只讲你每天都在遇到的那几下卡顿。

找图

为了找一张参考图，翻了 6 个文件夹

素材散在下载、桌面、微信、移动硬盘里，最后靠"我记得是上周存的"乱翻。

重复

同一张图存了 3 份，改了一份忘了另外两份

没有库就没有"唯一副本"：内容相同但文件名不同的图，肉眼根本认不出来。

预览

PSD、RAW、3D 文件全是白图标

只能靠文件名猜内容，打开一个要十几秒，翻十个就没了耐心。

批量

一百张图要改尺寸、改名，只能一张张来

想批量又怕覆盖原图，做完发现改错了还退不回去。

记忆

只记得"蓝调、海边、逆光"，不记得文件名

文件名是 IMG_4821，文件夹叫"新建文件夹 (2)"，关键词搜不到。

交付

客户要看方案，只能压缩包发过去

对方解压后一堆散图，没有顺序、没有备注，也看不出你在讲什么。

02

八个方面的功能，按你干活儿的顺序排

下面每一条都已经装进安装包里，不是"规划中"。看的时候可以直接对照你自己的工作流。

收集 从哪儿来都行

素材进来的方式，决定了你愿不愿意真的用它。

  • 拖拽 / 粘贴：文件拖进窗口；截图直接 Ctrl+V 入库。
  • 监听文件夹：指定几个目录，往里丢文件就自动导入，可设递归深度 1–16。
  • 截图入库：Ctrl+Shift+S 区域框选，存进当前库。
  • 手机扫码投送：同一 Wi-Fi 下手机浏览器选文件上传，不用装 App。
  • 条码拍摄流水线：拍完产品拍送货单，自动按条码分组、编号、裁切、入库。
  • 收件箱：新进来的先标"待整理"，侧栏统一过一遍再归档。

重复文件按内容自动跳过；大库重扫只处理新增与变化的部分。

整理 一个人也能建体系

不用一开始就想清楚分类，先收进来，再慢慢理。

  • 多层文件夹 + 多资源库：不同项目各建一库，互不串图，随时切换。
  • 一图多夹 + 标签树：一张图可同时在多个文件夹和标签下，不复制文件。
  • 文件夹外观与封面：emoji、主题色、自定义封面；夹内搜索自动继承夹标签。
  • 隐私空间：单个文件夹或整个库都能加密码，锁定后业务接口直接拒绝。
  • 堆叠：连拍、RAW+JPG 合成一组，网格里只占一条。
  • 智能文件夹：条件规则（AND/OR 嵌套）实时求值，可对命中项批量打标。
  • 自动去重：MD5 找完全重复，pHash 找视觉相似，换个文件名也认得出来。

元数据可导出为 CSV / JSON；XMP sidecar 可导入，方便与 Lightroom、digiKam 互通。

找 五种找法可叠加

"我知道我要哪张"这件事，应该在两秒内解决。

  • 中文子串搜索：不用分词，打两个字就命中标题、标签、备注的任意位置。
  • 语义搜索：直接描述画面（"海边 日落 逆光"），不用猜文件名。
  • 按图搜相似 / 按色系搜：给一张参考图或一个色号，找视觉上接近的。
  • 按图内文字搜（OCR）：截图、文档、海报里的字也能被搜到（Windows）。
  • 组合筛选：文件夹 + 标签 + 评分 + 格式 + 分辨率档 + 颜色，条件叠加收窄。
  • 保存筛选器：把一套搜索条件存成"现场"，下次一键回到同一屏。

搜索语法支持 tag: color: rating:>=4 folder: kind:video。

看 不用先打开别的软件

在库里直接预览，不用为"看一眼"启动 Photoshop。

  • 28 种相机 RAW：直接抽文件内嵌预览，EXIF、拍摄参数都有。
  • 11 种设计稿：PSD / PSB / AI / EPS / Sketch / XD / Figma / InDesign / Affinity / CDR 出预览图。
  • 9 种 3D 模型、8 种视频、8 种音频、4 种字体，都能站内查看。
  • PDF / Office / EPUB：PDF 与 Office 可预览，EPUB 能读目录与正文；Excel / CSV 在卡片里直接画出前几行。
  • 瀑布流 / 网格 / 文件夹收纳：三种铺法；时间线按年 → 月 → 日分组。
  • 全屏灯箱：键盘左右就能逛完整个库，`1`~`5` 打星，空格播放视频。

视频封面与时长自动提取，不用额外装解码包。

改 改错了一步退回去

图库不该是"只读相册"，日常的修改应该就地完成。

  • 裁切 / 旋转 / 调色 / 擦除 / 标注 / 超分。
  • 非破坏编辑：原图不动，改的是"操作记录"，随时还原；确认后「应用到底片」才写回。
  • 撤销 / 重做：默认 200 步、累计 2 GB 额度；每个版本都能回滚。
  • 批量处理：批量裁切、批量调色、批量改名、批量改信息、批量 OCR。
  • 自动构图：裁切时自动找画面主体。
  • 视频裁剪：裁掉头尾，导出 GIF / WebM。

所有写回原图的操作用前都会先备份一份，版本历史里能看到。

用 跟系统长在一起

素材最终都要"拿出去用"，这一步不能靠导出。

  • 直接拖出去：拖进 Photoshop、Figma、微信、资源管理器都认，落成真实文件。
  • 托盘常驻 + 全局热键：随时唤出，不用切窗口找；可设开机自启。
  • 局域网只读分享：给同事一个链接看图，密码 / 过期 / 禁止下载都能设。
  • 无限画布：把素材拖上去自由排布，拼成参考板。
  • 导出：ZIP 批量（可转码）、HTML 画廊、Eagle 包、CSV / JSON、ASE 色板。

安装版会接管常见图片 / 视频 / 音频的「打开方式」，双击就用它打开。

自动化 能被脚本和 AI 调用

你的库应该能被程序用，而不是只能用手点。

  • 本地开放 API：三级权限（read / write / ingest），自带 OpenAPI 文档与限流。
  • 5 个 MCP 工具：让 Claude 这类 AI 客户端直接检索、看收藏、套用智能文件夹。
  • 插件沙箱：5 类权限位，独立子进程，能干什么写在插件清单里。
  • 动作宏：把打标、归类、改名、AI 处理串成可复用动作，执行前先预览影响行数。
  • 夜间批处理：闲置时段自动跑 AI 分析，导入时自动让路。

适合批量整理、自动归档、接自己公司的内部流程。

数据 随时能带走

用得越久，越要在意"万一它没了怎么办"。

  • 库就在素材目录里：整库数据在 .tuku 下，连同素材一起拷走就换个机器继续用。
  • CSV / JSON / HTML 导出：库里的信息永远不会被锁死。
  • 元数据 CSV 导回：用 Excel 改完标题、评分、标签，再写回库。
  • 备份 + 同步快照：可设自动备份；同步盘只传库文件，原图不上去。
  • 回收站 + 库锁：删错了能捞回来；打开库要密码，防的是别人顺手翻（不是硬盘加密）。
  • 完整性自检：程序文件被安全软件隔离或写坏时能查出并补回。

离线授权：Ed25519 在本机验签，绑定「手机号 + 设备码」，断网也能用。

03

七个"别家没有或者做不顺手"的地方

这些是它真正区别于普通看图软件的地方——也是它值得单独装一个的理由。

01

中文子串搜索：打两个字就出

多数图库的关键词搜索要求"完整词"或先分词，你打"海边日"就搜不到"海边日落逆光"。这里用字符级全文索引，任意位置命中，中文尤其明显。

为什么少见：中文不分词还要快，需要对索引下很多额外功夫，多数产品直接放弃。

02

记得画面就能找：本机语义检索

你已经忘了文件名、标签、甚至哪一年存的，但记得"那个蓝调的、有个人站在窗边"。用一句描述去找，2 万张库里 49 ms 出结果。

为什么少见：模型跑在你自己的机器上，不上传图片，也不消耗云端额度。

03

拖出去就能用：跟设计软件直连

选中素材直接拖到 Photoshop 画布、Figma 里，落地就是一张图，不用先"导出到桌面"再拖一次。

为什么少见：网页版产品结构上做不到；桌面产品通常也懒得多做一步。

04

不上云，也能给同事看图

局域网只读分享：生成一个链接或二维码，同一网络里的人用浏览器就能翻你的选图集，带密码、可设过期、可禁止下载。

为什么少见：多数产品把分享做成云服务入口，纯本地产品往往干脆不做。

05

改图不毁原图：操作记录 + 双栈撤销

裁切、调色、擦除都是"记一笔"，原文件始终是原始字节；可以一路撤回，也能重做，还能回滚到任意一个历史版本。

为什么少见：真做非破坏要改整个存储模型，很多产品只是"备份一份再覆盖"。

06

让你的 AI 助手直接读你的素材库

内置 MCP 服务与带权限的本地 API：AI 客户端可以按你的指令检索、看收藏、套用智能文件夹——不是聊天，是真动手。

为什么少见：这一步等于把数据接口开放出来，多数商业产品不愿意。

07

两万张的库，翻起来还是顺的

滚动不是"一次加载全部"：分页用键集游标，列表走索引，缩略图有独立限速队列。深翻页 12 ms、关键词搜索 10 ms。

为什么少见：多数同类产品在两万张这个量级就开始转圈了。

04

快不快，看这几个数字就够了

全部是实测（本机 Windows、2 万张素材的库），5 次采样取中位数，数字越小越好。

你会在意的场景实测中位数换算成体感
导入 2 万个文件5,687 行/秒建库是"倒进去等一会儿"，不是等一整晚
打开素材列表6 ms点开就出，看不到转圈
翻到很后面的页12 ms越往后翻不会越慢
关键词搜索10 ms边打边出结果
按标签筛选10 ms条件叠加也不卡
语义搜索（2 万张）49 ms用一句话描述画面，眨眼内出结果
调色实时预览（720p）14 ms拖滑块是跟手的
调色实时预览（1600px）69 ms大图上调色仍可用，不卡死

参考：人眨一次眼约 100–400 ms。列表首屏第一次请求会连带预热缩略图，首次可能明显慢于上表。 "百万级"目前是目标而不是承诺，见下一节的"不足"。

05

三步就能用起来

不需要先读手册，也不需要整理好素材才能开始——它的设计前提就是"先乱着收，之后再理"。

1

装

从发布页下载 Windows 安装包，先用 certutil -hashfile 核对 Release 说明里的 SHA256，再双击安装。装到当前用户目录，不需要管理员权限。

2

建库

选一个空间大的本地文件夹当素材库。库数据写在里面的 .tuku 目录，原图不搬不改名。

3

拖进来

把文件或整个文件夹拖进窗口，或者让它监听你的下载文件夹。缩略图跑完就能搜、能筛、能拖出去用了。

几个能省时间的小知识
  • 空格快速预览，不用双击；Ctrl+K 命令面板，Ctrl+F 搜索，Ctrl+Z 撤销。
  • 先让缩略图跑完，再开 AI 分析——两层队列分开跑，不会互相抢 CPU。
  • 按 F1 打开应用内教程，可全文搜索；内容随版本更新，不依赖网络。
  • 库锁只拦"打开这个库"，不加密硬盘文件——把它当门禁，别当保险箱。
  • 第一次开语义搜索会下载约 90MB 的本地模型；不装也不影响其它功能。
06

它适合谁，不适合谁

一段话判断清楚，比看十屏截图有用。

用起来会很顺手

  • 一个人、一台 Windows 电脑做设计 / 摄影 / 内容。
  • 素材几万到几十万张，主要在本地硬盘或移动硬盘。
  • 需要批量整理、批处理、打包交付。
  • 想让脚本或 AI 客户端直接用上自己的素材库。
  • 在意"素材不被上传、格式不被绑架"。

典型用户：接私单的设计师、做自媒体的剪辑、需要管理参考图库的摄影爱好者、要按编码归档产品图的电商运营。

现在真的不合适

  • 团队多人共用一套素材，需要权限与审批。
  • 主力机是 macOS 或 Linux。
  • 需要在手机上随时随地看库、要云端自动同步。
  • 要开箱即管百万级素材。
  • 完全没有网络、又需要 AI 描述与自动打标。

这几条不是"以后也能凑合"，是现阶段确实做不到——它们都写在下一节的"不足"里。

07

先说清楚它哪里还不够好

一份只讲优点的介绍没什么用。以下是它目前真实的短板，以及为什么会这样。

七个已知短板

  • 没有代码签名证书。安装包与主程序可能被 360 / 火绒 / Defender 提示「未知发布者」。核对 Release 里的 SHA256 是唯一可靠的自证方式；装好后可在「设置 → 数据与维护 → 软件完整性」自检并补回被隔离的文件。
  • 只有 Windows 经过验收。macOS / Linux 有构建配置，但没做过真机验收，所以不对外宣称支持；系统 OCR 也只在 Windows 可用。
  • 没有云同步，没有手机 App，没有多人协作。最接近的替代是局域网只读分享与同步文件夹快照——前者只在同一网络可用，后者只同步库文件、不同步原图。
  • 英文界面还有盲区。界面、教程与文档已双语，但 AI 服务商与模型名等配置项仍显示中文。
  • 2 万张实测良好，百万级仍是目标。网格、时间线、清单都已窗口化渲染，滚动不随库变大而变慢；但百万级只有基准脚本，没有真机验收。
  • 首次开 AI 会比较慢。语义模型在 CPU 上跑，首次还要下载约 90MB 权重；白天算不完的索引可以交给「夜间批处理」在闲置时段补。
  • 安装包偏大（约 138 MB）。内含 Node 运行时、图像处理与推理库；已按平台裁掉用不上的部分，但整体仍不算轻。
为什么会有这些短板？ 这是一个单机优先的产品：原图不上传、账号不注册、数据不出本机。 云同步、协作与账号体系不是"写不出来"，而是做出来之后每个月都要为存储、带宽、备份和故障负责—— 那是一笔持续支出，也是一个不同的产品。所以它们被明确排除在当前版本之外，而不是含糊地写成"即将支持"。

它可能正好适合你，也可能完全不适合

"适合"那栏你点头超过三条，就值得装一个试试——素材始终在你自己的硬盘上， 卸载软件也不会带走或损坏你的文件。 "不适合"那栏你中了任何一条，就别勉强：现阶段它确实不是为那种用法设计的。
