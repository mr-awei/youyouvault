01

It solves these very concrete everyday annoyances

No talk of empowerment or ecosystems — only the little stalls you hit every day.

Finding

Six folders deep just to find one reference image

Assets are scattered across Downloads, Desktop, WeChat and external drives, so you end up rummaging on a hunch.

Duplicates

The same image saved three times, one edited, two forgotten

Without a library there is no single copy: identical content under different filenames is invisible to the eye.

Preview

PSD, RAW and 3D files are all blank icons

You guess from the filename, each file takes ten seconds to open, and after ten of them your patience is gone.

Bulk work

A hundred images to resize and rename, one at a time

You want batch processing but fear overwriting originals — and when it goes wrong there is no way back.

Memory

You remember 'blue tone, seaside, backlit' but not the filename

The file is IMG_4821 and the folder is 'New folder (2)'. Keywords find nothing.

Delivery

The client wants to see the options, so you send a zip

They unpack a pile of loose images with no order, no notes, and no idea what you were saying.

02

Eight areas of functionality, ordered the way you actually work

Every item below is already in the installer — none of it is 'planned'. Read it against your own workflow.

Collect from anywhere

How assets get in decides whether you actually use the tool.

  • Drag / paste: drop files into the window, or paste a screenshot straight in with Ctrl+V.
  • Folder watching: point it at a few directories and new files import themselves; recursion depth 1–16.
  • Capture to library: Ctrl+Shift+S and drag a region — it lands in the current library.
  • Phone upload by QR: on the same Wi-Fi, pick files in a mobile browser. No app to install.
  • Barcode shooting pipeline: shoot products then the delivery note; group by barcode, number, crop and file automatically.
  • Inbox: new arrivals are marked 'to sort' so you can sweep them in one pass later.

Duplicate files are skipped by content; rescanning a large library only touches new and changed files.

Organise a system for one person

You don't need the taxonomy up front — collect first, sort later.

  • Nested folders + multiple libraries: one library per project, no cross-contamination, switch any time.
  • One image, many folders + tag tree: an image can live in several folders and tags without being copied.
  • Folder appearance and covers: emoji, accent colour, custom cover; in-folder search inherits the folder's tags.
  • Private space: lock a single folder or the whole library; while locked, business endpoints refuse outright.
  • Stacks: bursts or RAW+JPG become one entry in the grid.
  • Smart folders: nested AND/OR rules evaluated live; bulk-tag everything that matches.
  • Automatic dedupe: MD5 for exact duplicates, pHash for visual near-duplicates — a renamed copy is still recognised.

Metadata exports to CSV / JSON; XMP sidecars import, so Lightroom and digiKam round-trip cleanly.

Find five ways, stackable

'I know which one I want' should take two seconds.

  • Chinese substring search: no tokenisation — two characters match anywhere in title, tags or notes.
  • Semantic search: describe the scene ('seaside sunset backlit') instead of guessing a filename.
  • Search by similar image / by colour: hand it a reference image or a hex colour and find what looks close.
  • Search text inside images (OCR): text in screenshots, documents and posters is searchable too (Windows).
  • Combined filters: folder + tags + rating + format + resolution tier + colour, narrowing as you stack them.
  • Saved filters: store the whole search as a 'scene' and jump back to the same screen in one click.

Search syntax supports tag: color: rating:>=4 folder: kind:video.

View without launching anything else

Preview inside the library instead of opening Photoshop just to take a look.

  • 28 camera RAW formats: embedded previews extracted directly, with EXIF and shooting data.
  • 11 design formats: PSD / PSB / AI / EPS / Sketch / XD / Figma / InDesign / Affinity / CDR all get previews.
  • 9 3D formats, 8 video, 8 audio and 4 font formats all open in-app.
  • PDF / Office / EPUB: PDF and Office preview, EPUB with table of contents and body text; Excel / CSV draw their first rows on the card.
  • Masonry / grid / folder shelves: three layouts; the timeline groups by year → month → day.
  • Full-screen lightbox: arrow keys walk the whole library, `1`–`5` set ratings, Space plays video.

Video posters and durations are extracted automatically — no extra codec pack.

Edit one step back when you fumble

A library shouldn't be a read-only album; everyday edits belong right here.

  • Crop / rotate / grade / erase / annotate / upscale.
  • Non-destructive editing: the original never changes — edits are an operation log you can undo any time; only 'apply to negative' writes back.
  • Undo / redo: 200 steps and a 2 GB budget by default; every version can be rolled back.
  • Batch work: batch crop, batch grade, batch rename, batch metadata, batch OCR.
  • Auto composition: cropping finds the subject for you.
  • Video trim: cut head and tail, export GIF / WebM.

Anything that writes back to the original is backed up first, visible in version history.

Use grown into the OS

Assets eventually have to go out and be used — that step can't mean exporting first.

  • Drag straight out: into Photoshop, Figma, WeChat or Explorer — it lands as a real file.
  • Tray + global hotkeys: summon it any time without hunting for a window; optional launch at login.
  • LAN read-only sharing: give a colleague a link to browse your selection — password, expiry and download blocking included.
  • Infinite canvas: drag assets around freely and assemble a reference board.
  • Export: batch ZIP (with transcoding), HTML gallery, Eagle package, CSV / JSON, ASE swatches.

The installed build registers common image / video / audio file associations — double-click opens it here.

Automate callable by scripts and AI

Your library should be usable by programs, not only by hand.

  • Local open API: three permission levels (read / write / ingest), OpenAPI docs and rate limiting built in.
  • Five MCP tools: AI clients such as Claude can search, list favourites and apply smart folders directly.
  • Plugin sandbox: five permission bits, separate child process, capabilities declared in the manifest.
  • Action macros: chain tagging, filing, renaming and AI passes into a reusable action, with a preview of affected rows.
  • Nightly batch: AI analysis runs in idle hours and yields while an import is in progress.

Good for bulk sorting, automatic filing and wiring into your own internal process.

Data always portable

The longer you use it, the more you care about 'what if it disappears'.

  • The library lives with the assets: all data sits under .tuku; copy the folder to another machine and keep going.
  • CSV / JSON / HTML export: your information is never locked in.
  • CSV round-trip: edit titles, ratings and tags in Excel, then write them back into the library.
  • Backup + sync snapshots: optional automatic backups; a sync folder only carries library files, never the originals.
  • Trash + library lock: recover a mistaken delete; the lock requires a password to open the library (a door, not disk encryption).
  • Integrity self-check: detects program files quarantined or damaged by security software and restores them.

Offline licensing: Ed25519 verified locally, bound to 'phone + device code', works without a network.

03

Seven things others don't have, or don't do comfortably

These are what actually set it apart from a plain image viewer — and why it deserves its own install.

01

Chinese substring search: two characters and it's there

Most libraries require a whole word or tokenise first, so typing 'seaside sun' finds nothing for 'seaside sunset backlit'. Here a character-level full-text index matches anywhere — very visible in Chinese.

Why it's rare: getting Chinese right without tokenisation and staying fast takes a lot of extra index work; most products simply skip it.

02

Remember the picture, not the file: local semantic search

You've forgotten the filename, the tags, even the year — but you remember 'that blue-toned one with someone standing by the window'. Describe it; 49 ms across 20,000 images.

Why it's rare: the model runs on your own machine, so no images are uploaded and no cloud credits are burned.

03

Drag it out and use it: wired into your design tools

Drag a selection straight onto a Photoshop canvas or into Figma — it arrives as an image, without exporting to the desktop first.

Why it's rare: web products structurally can't do it; desktop products usually don't bother with the extra step.

04

Share a selection without going to the cloud

LAN read-only sharing: generate a link or QR code and anyone on the same network can browse your selection in a browser — with a password, an expiry and downloads disabled if you like.

Why it's rare: most products turn sharing into a cloud funnel; fully local products often skip it altogether.

05

Edit without destroying: operation log + two-stack undo

Crop, grade and erase are recorded as operations; the original file stays byte-identical. Undo back, redo forward, or roll back to any historical version.

Why it's rare: real non-destructive editing reshapes the whole storage model; many products just back up a copy and overwrite.

06

Let your AI assistant read your library directly

A built-in MCP server and a permissioned local API: AI clients can search, list favourites and apply smart folders on your instruction — not just chat, but act.

Why it's rare: it means opening up the data interface, which most commercial products won't do.

07

A 20,000-image library still scrolls smoothly

Scrolling doesn't load everything at once: keyset-cursor paging, indexed lists and a separately throttled thumbnail queue. 12 ms deep paging, 10 ms keyword search.

Why it's rare: most comparable products start spinning at the 20,000-image mark.

05

Three steps to get going

No manual to read first, and no need to tidy your assets beforehand — it is designed for 'collect messily, sort later'.

1

Install

Download the Windows installer, verify the SHA256 from the release notes with certutil -hashfile, then double-click. It installs into your user folder and needs no administrator rights.

2

Create a library

Pick a roomy local folder as your library. Library data goes into .tuku inside it; originals are never moved or renamed.

3

Drop things in

Drag files or whole folders into the window, or let it watch your Downloads folder. Once thumbnails finish you can search, filter and drag assets out.

A few time-savers
  • Space previews without double-clicking; Ctrl+K command palette, Ctrl+F search, Ctrl+Z undo.
  • Let thumbnails finish before starting AI analysis — the two queues run separately and won't fight over the CPU.
  • Press F1 for the in-app tutorial with full-text search; it ships with each version and needs no network.
  • The library lock only gates opening that library; it doesn't encrypt files on disk — treat it as a door, not a safe.
  • The first semantic search downloads a ~90 MB local model; skipping it affects nothing else.
06

Who it suits, and who it doesn't

One paragraph of honesty beats ten screenshots.

It will feel natural if you

  • Work alone on one Windows machine in design / photography / content.
  • Keep tens of thousands of assets mostly on local or external drives.
  • Need bulk sorting, batch processing and packaged delivery.
  • Want scripts or AI clients to use your library directly.
  • Care that 'assets aren't uploaded and formats aren't locked in'.

Typical users: freelance designers, video editors running their own channels, photographers managing reference libraries, e-commerce operators filing product shots by code.

It genuinely doesn't fit if you

  • Share one asset pool across a team and need permissions and approvals.
  • Mainly use macOS or Linux.
  • Want to browse the library on your phone anywhere, with automatic cloud sync.
  • Expect to manage a million assets out of the box.
  • Have no network at all yet need AI descriptions and auto-tagging.

These aren't 'we'll manage for now' — they really don't work today, and they're all listed in the shortcomings below.

07

Let's be clear about where it falls short

An overview that only lists strengths is useless. These are the real weaknesses, and why they exist.

Seven known shortcomings

  • No code-signing certificate. The installer and main executable may be flagged as 'unknown publisher' by 360 / Huorong / Defender. Verifying the SHA256 in the release notes is the only reliable self-check; after installing, 'Settings → Data & Maintenance → Software integrity' can detect and restore quarantined files.
  • Only Windows has been validated. macOS / Linux have build configs but no real-machine validation, so they aren't claimed as supported; system OCR is Windows-only as well.
  • No cloud sync, no mobile app, no multi-user collaboration. The closest substitutes are LAN read-only sharing and sync-folder snapshots — the first only works on the same network, the second only syncs library files, not originals.
  • The English UI still has blind spots. UI, tutorial and docs are bilingual, but AI provider and model settings still display Chinese.
  • 20,000 images are solid; million-scale is still a goal. Grid, timeline and playlists are all windowed, so scrolling doesn't slow as the library grows — but million-scale only has a benchmark script, no real-machine validation.
  • AI is slow the first time. The semantic model runs on CPU and the first run downloads about 90 MB of weights; whatever can't finish during the day can be picked up by nightly batch processing.
  • The installer is large (about 138 MB). It bundles the Node runtime, image processing and inference libraries; unused parts are trimmed per platform, but it still isn't light.
Why these shortcomings? This is a single-machine-first product: originals are never uploaded, no account is created, data never leaves the machine. Cloud sync, collaboration and accounts aren't 'too hard to build' — building them means being responsible every month for storage, bandwidth, backups and outages. That's an ongoing cost and a different product. So they are explicitly out of scope for this version, instead of being vaguely promised as 'coming soon'.

It may fit you exactly, or not at all

If you nodded at more than three items in the 'suits you' column, it's worth an install — your assets stay on your own drive, and uninstalling won't take them away or damage them. If you hit any item in the other column, don't force it: this version genuinely isn't designed for that.
