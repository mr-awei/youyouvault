规则说明

  • 手机号 ↔ 设备：多对多。一个手机号可以签多台设备；同一台设备也可以签给多个手机号（各自一份激活码）。
  • 设备码：由 MachineGuid、CPU ProcessorId、主板序列号、系统盘卷序列号各取 SHA-256 前 4 位组成。
  • 会变的情况：换主板 / CPU / 系统盘、重装或克隆系统、系统盘重新格式化、虚拟机迁移。4 段允许变 1 段，变 2 段需重新签发。
  • 取消授权：签发记录只是台账；真正让客户端失效要把手机号或设备加入停用清单，并让客户端能访问到清单地址。

授权记录

停用手机号

该手机号名下的所有设备一起锁定。适用于离职、违约、整账号退款。

停用设备

只锁定这一台设备，同手机号下的其它设备不受影响。

签名停用清单

客户端启动 / 手动刷新授权时会拉取并用内置公钥验签。把清单放到任意静态 HTTPS 地址，再让软件设置 TUKU_LICENSE_REVOKE_URL 指向它即可。本工具也临时提供本机地址，便于测试。
