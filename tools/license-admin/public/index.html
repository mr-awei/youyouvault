授权规则

  • 每个授权码固定绑定一个手机号 + 一台设备，不能跨手机号复用。
  • 同一台设备多人使用时，每个手机号分别签发自己的授权码；取消其中一条不影响其他人。
  • 取消授权会写入停用清单，客户端联网刷新后生效；恢复授权后同样需要客户端刷新。

已授权
